# Prem Poddar's Homebrew tap

Apps by [Prem Poddar](https://prempoddar.is-a.dev).

## Brewlight

Spotlight, but for brew. A fast, native Mac app for everything you do with Homebrew.

```bash
brew install --cask prempoddar/tap/brewlight
```

Update it with `brew upgrade --cask brewlight`. More at
[prempoddar.github.io/Brewlight](https://prempoddar.github.io/Brewlight/).
